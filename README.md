# משק 32 – חסטולרו

אתר הזמנות בעברית וב־RTL למשק משפחתי. הפרויקט מחולק ל־Frontend ב־React/TypeScript ול־Backend ב־Java/Spring Boot.

## מה כבר עובד

- הזמנה כאורחת עם שם וטלפון הנשמרים במאגר לקוחות.
- קטלוג, סל, מגבלות כמות ובדיקת זמינות בצד השרת.
- יצירת הזמנה אמיתית ושמירת פרטי נקודת האיסוף והדרך המבוקשת לתשלום.
- מסך מנהל מוגן: הזמנות, סינון לפי לקוח, מוצר, נקודת חלוקה ואריזה; עדכון סטטוס, תיבת "נארזה", הערות ומאזן.
- בחירת Bit/PayBox מסומנת במערכת, ללא קישור או אימות תשלום עד לחיבור לספק תשלומים רשמי.

## הפעלה מקומית

1. פתחי PowerShell בתיקיית הפרויקט והגדירי פרטי מנהל זמניים לסשן המקומי:

```powershell
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "בחרי-סיסמה-חזקה-מקומית"
```

2. הפעילי את ה־Backend. אם Maven לא מותקן, אפשר להשתמש ב־Maven Wrapper; ב־Windows מסוים יש צורך ב־Maven מקומי.

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

3. בחלון נפרד הפעילי את ה־Frontend:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

4. פתחי `http://127.0.0.1:5173/` ולחצי על "כניסת מנהל" כדי להגיע לממשק הניהול.

## מסד נתונים

בפיתוח השרת משתמש ב־H2 מקומי; הקובץ שלו נשמר ב־`backend/data/` ואינו נכנס ל־Git. בפריסה משתמשים בפרופיל `prod` ומספקים PostgreSQL באמצעות משתני הסביבה שב־`.env.example`.

## אבטחה

שם וטלפון מזהים לקוח אך אינם התחברות מאובטחת. לפני פתיחת חשבונות לקוח יש להוסיף קוד חד־פעמי ב־SMS. נתיבי המנהל מאומתים בשרת, ויש להגדיר את פרטי הגישה רק במשתני סביבה.
